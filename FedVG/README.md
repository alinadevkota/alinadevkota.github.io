# FedVG: Gradient-Guided Aggregation for Enhanced Federated Learning

This repository contains the source code for the [FedVG project website](https://alinadevkota.github.io/FedVG/).

FedVG is a gradient-guided federated aggregation framework designed to improve learning
under client data heterogeneity. By using a global validation set and layerwise validation
gradient norms, FedVG adaptively weights client models based on their generalization
behavior rather than relying only on client dataset size. Experiments across natural and
medical image benchmarks show improved performance, particularly in highly heterogeneous
federated learning settings.
